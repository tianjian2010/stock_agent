# 妙想金融数据 (mx_data)

基于东方财富 API 的金融数据查询工具，支持实时行情、财务数据、资金流向等查询。

## API 信息

- **接口地址**: `https://mkapi2.dfcfs.com/finskillshub/api/claw/query`
- **请求方式**: POST
- **API Key**: 从环境变量 `MX_API_KEY` 读取

## 使用方法

### 查询股票实时行情

直接告诉我要查询的股票和指标，例如：
- "查询东方财富的股价"
- "贵州茅台最新价"
- "招商银行今日行情"

### 查询资金流向

- "查询XXX股票的主力资金流向"
- "今日板块资金流向"

### 查询财务数据

- "查询XXX的财务指标"
- "招商银行市盈率"

### 查询板块行情

- "今日证券板块行情"
- "新能源板块涨跌"

## 脚本调用

```bash
# 查询示例
node /workspace/skills/mx_data/scripts/query.js "东方财富最新价"
```

## 输出格式

API 返回 JSON 格式数据，包含：
- 证券代码、名称
- 最新价、涨跌幅、成交量
- 资金流向
- 财务指标等

## 注意事项

- 查询范围过大可能导致返回数据过多
- 涉及3年以上日线数据需谨慎
- 数据来自东方财富，权威及时
