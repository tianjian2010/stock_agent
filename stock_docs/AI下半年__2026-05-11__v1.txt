
【天风计算机 缪欣君】重要产业主题之大局观：

AI 下半年展望: 从NV CUDA生态到国产算力生态，从Vibe coding到Agent Engineering

1、硬件：
1） 国产算力线: 昇腾链、双王、壁仞、昆仑芯

核心逻辑:

1、若昇腾在 Q3 放量，DS Token 份额有望进一步提升

根据美国国家人工智能标准与创新中心测评报告， DS V4已是他们测评过中国最强大模型。DS官方已明确“预计下半年昇腾950 超节点批量上市，Pro 的价格会大幅下调”。目前，DeepSeek-V4-Pro模型 API 限时 2.5 折至 5 月 31 日。若昇腾 Q3 放量，我们认为这一折扣将成为常态甚至折扣会更低。

2、性价比驱动，“DS+国产算力”生态有望实现“弯道超车”

黄仁勋近期表示“#DS首发于昇腾平台是灾难性的”，这侧面验证生态的重要性。Ornn Compute 价格指数显示，英伟达高端显卡租赁较两月前已上涨 48%。若涨势延续，昇腾为代表的国产算力推理性价比有望进一步提升。单 Token 性价比为先，我们认为“DS+国产算力”有望成为“模芯”组合的新范式，其他可关注“阿里 PPU+通义”组合。

3、从 Claude+Asic 到 DS/GLM+国产算力，从 Vibe coding 到 Agent Engineering<br />
过去一年， AI 应用的发展主要与 Vibe coding 驱动有关（以 Claude 为代表，搭配亚马逊和谷歌的 Asic 芯片）。展望未来一年， coding有望进一步深入至企业软件，将其重构为 Agent（以DS和GLM为代表，搭配昇腾等国产算力芯片），我们看好企业内部知识库的建立以及#会计记账/营销客服/法律与文书等 企业Agent搭建等环节首先加速。

超节点之后，我们预计华为有望将重要精力投入一体机和边缘产品。 考虑 DeepSeek-V4-Flash 仅 284B 参数量和 950PR 的显存大小， 软硬一体形态的#一体机有望成为部分企业的重要选择。近期，深信服发布 AI 超融合，助力企业构建 Agent 的基础设施。
