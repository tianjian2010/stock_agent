
关于投研部渠道近期持续力推之天岳先进（688234），一份调研纪要：

天岳先进是碳化硅行业市占率第一的龙头公司。
经过数10年的努力，已超越美国wolfspeed公司，成为全球老大。

十年前硅化硅六英寸片，一片价格2万人民币。价格太高，导致很多行业用不起。2020年新能源高端车型和快充充电桩中，开始使用碳化硅的模块，但使用量并不大。

后续在行业扩产及价格战背景下，六英片价格降至1900RMB，可用于两辆车。每辆车只需八九百元，可以替代IGBT了。

但价格战直接结果就是全行业亏损，大量中小企业倒闭出局，连原来排名第一的wolfspeed的都被迫破产重组。

天岳 A股和港股两次上市，烧了30多亿成为行业市占率第一的老大，但2025年也出现了亏损。港股融资的17亿资金目前还没有动用。
天岳先进2025年营收约14.6亿元，业绩亏损 2亿。

公司目前产能主要在济南，年产能26万片，以六寸为主，部分八寸。
新投产的上海临港基地，年产能96万片，以8寸为主，2026年底全部投产。8寸价格约4000，良率可以做到80以上。
12寸已经试产成功，价格约2万元. 目前在良率很低，在提升过程中.
济南2期扩产也在进行中，150亩土地，未来也能扩到90万片以上。

过去碳化硅价格昂贵，主要用在新能源车和充电桩上
现在新增了三个需求应用场景

1. HVDC电源：全面替代MOSFET → 确定性强
2. 封装：部分替代硅中介层 → 未来核心看点, 进入台积电COWOS产业链
3. 光模块：搭配不替代陶瓷 → 辅助散热配角
4. AR光学：全新增量蓝海

一、数据中心高压电源（当前最快放量、确定性最高）
1. 应用：AI服务器PSU、高压DC-DC、机架配电、UPS、800V机柜高压总线
2. SiC角色：功率开关芯片（MOSFET）
3. 对比硅基IGBT/GaN
开关损耗降70%+，电源效率冲到99.2%+
耐高温、高频化，大幅缩小电源体积
适配万瓦级AI集群，压低PUE，一年省巨额电费
4. 落地节奏：2026大规模渗透，英伟达AMD全栈切换
5. 壁垒：车规级产能平移，良率快速爬坡

二、CoWoS先进封装（未来弹性最大、估值高）
1. 应用：英伟达H100/H200/B200下一代Chiplet
2. SiC角色：SiC中介层 / 超高导热散热基板
3. 对比硅中介层
导热≈硅3倍，解决1000W+巨热瓶颈
热膨胀匹配硅，大晶圆不翘曲、良率更高
高频寄生更低，适配HBM超短互联
4. 落地节奏：2027量产导入，2028主力替代
5. 壁垒：12英寸单晶SiC、晶圆键合、TSV通孔工艺
台积电验证已过，等待量产。

三、高速光模块   CPO光电融合（高端增量，不替代陶瓷）
1. 应用：800G/1.6T/3.2T光模块、CPO共封装光学
2. SiC角色：背部散热热沉、复合基板底层，不做高频线路层
3. 对比氮化铝AlN
导热碾压AlN，但介电差、高频损耗大
只能辅散热，永远抢不走AlN信号基板份额
4. 落地节奏：2026高端3.2T开始标配
5. 格局：AlN走信号 + SiC走散热，叠层复合方案

四、AR/AI智能眼镜（全新小众高毛利赛道）
1. 应用：光波导镜片、光学基底、微型算力散热
2. SiC角色：光学窗口、轻量化高透基底
3. 优势
折射率极高、重量仅玻璃1/5
耐高温不变形，适配AI端侧SoC密集散热
4. 落地节奏：2027起头部AR量产搭载
5. 特点：用量小、单价极高，纯材料溢价
