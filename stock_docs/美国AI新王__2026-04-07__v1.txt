
美国AI新王

无数历史实践证明，美国（或者说美股）科技市场的方向，一定极大左右了中国A股市场在科技领域的方向。所以，如果美国AI市场内部出产了估值最高品种的切换，那一定是产业上影响巨大的事件。

美国产业圈子的精英朋友，近期交流，实际上，OpenAI 还是老大，现状是，OpenAI 名气大、估值高，但 Anthropic 赚钱逻辑更硬。大家私底下都在抢着买 Anthropic的老股，且认为Anthropic将成为新的美国AI估值王者。

目前OpenAI 的官方估值（约 8500 亿美元）目前仍高于 Anthropic（约 3800 亿美元），但在私下的二级市场（老股交易）里，OpenAI 遇冷：投资者觉得它太贵了，甚至有人愿意打折出售老股，需求疲软。Anthropic 爆火，大家抢着买，甚至愿意溢价（加价）买。市场普遍认为它的实际价值被低估了，未来的增长空间更大。

两家公司最大的区别：

OpenAI靠 ChatGPT 吸引了全球几亿普通用户，名气大，追求“全能”，什么火做什么，视频生成（Sora）、语音、绘图都要搞，但要把利润变现，难度大。

Anthropic专注做“企业生意”。它不追求几亿用户，而是专门服务金融、法律、编程等高价值客户。比如它的代码生成工具，能直接帮大公司省几百万美元，企业非常愿意为此买单。它的单用户收入是 OpenAI 的几十倍。

外资行关于Anthropic 的盈利逻辑拆解：

1.核心引擎：API 消耗型收入模型

与 OpenAI 收入很大一部分来自 ChatGPT 的个人订阅不同，Anthropic 高达 85% 以上的收入来自于企业和开发者通过 API 调用其模型。

2.Anthropic锁定高价值“杀手级应用”

精准地选择了代码生成作为其首个企业级杀手应用（Claude Code）。

高消耗：代码生成任务消耗的 Token 量是普通聊天的 10 到 50 倍，商业化天花板极高。

强刚需：自动化开发是所有科技公司的核心痛点，预算充足，且一旦工作流被绑定，迁移成本非常高。

目前，Claude Code 已成为其收入增长的核心驱动力，年化收入已超过数十亿美元。

3.&nbsp; Anthropic 没有自建庞大的销售团队，而是将自己的模型深度集成到亚马逊 AWS 和谷歌云等巨头的平台中。云厂商通过销售 Anthropic 的模型来驱动自身云业务的增长，形成了资本和业务的双重闭环。

对于中国市场投资可以借鉴的经验是：Anthropic深耕企业级（B端）市场，跑通了盈利逻辑。这与 OpenAI 目前更多依赖 C 端流量和庞大基础设施投入的现状不同。类似的经验可以推导出，中国市场的下一步，我们要超级重视B端，要超级重视垂直领域应用。

这一逻辑证据下，推导出A股的中控技术（688777）是特别要重视的标的。

中控在流程工业领域深耕超过 30 年，服务超过 3.7 万家工业企业客户，累计部署控制系统超 10 万套。这种对工业流程、工艺和痛点的积累，是任何通用AI公司无法复制的。基于长期的服务，中控技术构建了规模达 100EB 的工业数据资源，覆盖石化、化工、电力等 50 多个细分行业。这些真实、高质量的工业数据是训练和优化其工业 AI 模型的核心基础。

中控的大模型能将 AI 的决策与工业现场的“执行”环节（如控制系统）无缝连接，实现从“自动化”到“自主化”的跨越。这种“感知-认知-决策-执行”的完整闭环能力是其核心竞争力。

可以把美国Anthropic理解为一个面向所有行业的智能基础设施，而中控技术则是在工业这个垂直领域。两者都是B端市场的王者。从行业讲，客观看，中控理论上要比Anthropic估值低很多，Anthropic目前在美国实际上5000亿估值还抢不到老股份额，而目前中控仅仅70+亿美金市值，是严重低估。&nbsp; 有投研感悟，很可能过两年后头看中控，会有回看2010年之前茅台股票价格的感觉，当时便宜到匪夷所思，我们怎么不去配置呢？

短期中控有一个市场猜测的大股东不太意愿大涨的因素，他的股权激烈股份暂时没有在二级市场购买完毕。这个因素，渠道没有办法去判断究竟是真实压制还是心里压制。如果真有压制，到9、10月份就会从规则上排除，增持期限截止。而另一种可能，如果美国一股产业大风潮刮过来，那就什么人为压制的鬼故事说法都不存在了。
